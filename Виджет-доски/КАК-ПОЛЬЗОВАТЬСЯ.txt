ВИДЖЕТ «ДОСКА ЦЕЛИ»
===================

ЧТО НУЖНО СДЕЛАТЬ ОДИН РАЗ:
1. Скопируй папку «Виджет-доски» к себе, например в D:\Личное\Моя цель
   (туда, где уже лежит файл «Доска-цели.html» — виджет найдёт его рядом).
2. Дважды кликни «Запустить-виджет.bat».
   Первый запуск скачает Electron (~100 МБ, один раз) — просто подожди.

КАК ПОЛЬЗОВАТЬСЯ КАЖДЫЙ ДЕНЬ:
- Двойной клик по «Запустить-виджет.bat» (или ярлыку на рабочем столе) —
  чёрного окна не будет, появится только сам виджет у правого края экрана.
- Виджет занимает половину экрана и висит поверх всех окон.
- Кнопка «—» наверху — свернуть. Вернуть — из панели задач или из значка
  в трее (возле часов, может прятаться под стрелочкой ^).
- Кнопка-булавка — закрепить/открепить «поверх всех окон».
- За верхнюю панель с прогрессом виджет можно перетаскивать,
  за край — растягивать, как обычное окно.
- Правый клик по значку в трее: показать, свернуть, «поверх окон», выйти.

ЯРЛЫК НА РАБОЧИЙ СТОЛ:
Правый клик по «Запустить-виджет.bat» -> «Отправить» -> «Рабочий стол».

ЕСЛИ ВИДЖЕТ НЕ НАХОДИТ ДОСКУ:
Просто положи файл «Доска-цели.html» внутрь папки «Виджет-доски».
